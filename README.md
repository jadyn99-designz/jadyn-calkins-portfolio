# Jadyn Calkins — Portfolio

Personal portfolio site for **Jadyn Calkins**, Product Designer / UI·UX Designer.

A single-page static site built with hand-written HTML5 + CSS — no build step,
no framework. Features a retro/pixel aesthetic with a pure-CSS `box-shadow`
pixel skater character.

## Stack
- Plain HTML5 + CSS (single `index.html`)
- Google Fonts: Press Start 2P, Bebas Neue, Space Mono
- Deployed as a static site on Vercel

## Develop locally
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy
Pushes to `main` auto-deploy via Vercel.
